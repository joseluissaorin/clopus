# PDF Manipulation

PDF generation, editing, and manipulation.

## Tools

- **pypdf**: PDF manipulation (merge, split, rotate)
- **ReportLab**: PDF generation from scratch
- **WeasyPrint**: HTML to PDF
- **pdf2image**: PDF to images
- **pdfplumber**: PDF text extraction

## pypdf Operations

```python
from pypdf import PdfReader, PdfWriter, PdfMerger

# Read PDF
reader = PdfReader("document.pdf")
print(f"Pages: {len(reader.pages)}")

# Extract text
for page in reader.pages:
    print(page.extract_text())

# Merge PDFs
merger = PdfMerger()
merger.append("doc1.pdf")
merger.append("doc2.pdf")
merger.write("merged.pdf")
merger.close()

# Split PDF
writer = PdfWriter()
for page in reader.pages[:5]:  # First 5 pages
    writer.add_page(page)
writer.write("first_five.pdf")

# Rotate page
page = reader.pages[0]
page.rotate(90)

# Add watermark
watermark = PdfReader("watermark.pdf")
for page in reader.pages:
    page.merge_page(watermark.pages[0])
```

## Generate PDF with ReportLab

```python
from reportlab.lib.pagesizes import letter
from reportlab.pdfgen import canvas
from reportlab.lib.units import inch

def create_pdf(filename):
    c = canvas.Canvas(filename, pagesize=letter)
    width, height = letter

    # Add text
    c.setFont("Helvetica-Bold", 24)
    c.drawString(1*inch, height - 1*inch, "Report Title")

    c.setFont("Helvetica", 12)
    c.drawString(1*inch, height - 1.5*inch, "Generated by CLOPUS")

    # Add image
    c.drawImage("logo.png", 1*inch, height - 3*inch, width=2*inch, height=1*inch)

    # Add table
    data = [["Name", "Value"], ["Item 1", "100"], ["Item 2", "200"]]
    from reportlab.platypus import Table
    table = Table(data)
    table.wrapOn(c, 400, 200)
    table.drawOn(c, 1*inch, height - 5*inch)

    c.save()
```

## HTML to PDF with WeasyPrint

```python
from weasyprint import HTML, CSS

# From URL
HTML('https://example.com').write_pdf('page.pdf')

# From HTML string
html_content = """
<!DOCTYPE html>
<html>
<head>
    <style>
        body { font-family: Arial; }
        h1 { color: #333; }
    </style>
</head>
<body>
    <h1>Report</h1>
    <p>Generated content here.</p>
</body>
</html>
"""
HTML(string=html_content).write_pdf('report.pdf')

# With custom CSS
css = CSS(string='@page { size: A4; margin: 1cm }')
HTML(string=html_content).write_pdf('styled.pdf', stylesheets=[css])
```

## Extract Data with pdfplumber

```python
import pdfplumber

with pdfplumber.open("document.pdf") as pdf:
    for page in pdf.pages:
        # Extract text
        text = page.extract_text()

        # Extract tables
        tables = page.extract_tables()
        for table in tables:
            for row in table:
                print(row)
```

## Best Practices

1. Use pypdf for simple operations
2. Use ReportLab for complex generation
3. Use WeasyPrint for HTML-based PDFs
4. Handle large PDFs in chunks
5. Compress PDFs for web delivery
6. Test with various PDF readers
7. Preserve accessibility features
