# React Todo App

Build a complete React Todo application with the following features:

## Core Features
1. **Add todos** - Users can add new todo items
2. **Complete todos** - Users can mark todos as complete/incomplete
3. **Delete todos** - Users can remove todos
4. **Filter todos** - Show all, active, or completed todos
5. **Clear completed** - Button to remove all completed todos
6. **Todo count** - Display number of items left

## Technical Requirements
- React 18 with TypeScript
- Vite for build tooling
- Tailwind CSS for styling
- Dark/Light mode toggle
- Local storage persistence
- Responsive design (mobile-friendly)

## Testing Requirements
- Unit tests with Jest for core logic
- E2E tests with Playwright for user flows
- Screenshot each test step

## Quality Requirements
- ESLint + Prettier formatting
- 80%+ test coverage
- All validation stages must pass
