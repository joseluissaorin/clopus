# Complex HTML5 Dashboard

Create a single-page HTML5 dashboard in /workspace/dashboard/ with the following:

1. **Pure HTML5 + CSS3 + Vanilla JavaScript** (no frameworks)
2. **Responsive design** that works on mobile and desktop
3. **Dark/Light theme toggle** with CSS custom properties
4. **Interactive charts** using Canvas API:
   - Line chart for time series data
   - Bar chart for comparisons  
   - Pie chart for distribution
5. **Real-time clock** with multiple timezone support
6. **Drag-and-drop widgets** that can be rearranged
7. **Local storage persistence** for widget positions and theme
8. **Animated transitions** using CSS animations
9. **Keyboard shortcuts** for navigation
10. **Accessibility** with proper ARIA labels

The dashboard should demonstrate advanced HTML5 features without any external dependencies.
