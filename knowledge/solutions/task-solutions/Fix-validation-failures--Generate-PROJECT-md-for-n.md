### Problem Identified
The E2E tests in `/workspace/todo-project/e2e/todo-app.spec.ts` were failing with a **strict mode violation** error. The issue was in the Dark Mode Tests where the test was using a complex selector pattern:

```typescript
// OLD (problematic)
const themeToggle = page.getByRole('button', { name: /theme|dark|light|mode/i }).or(
  page.locator('button').filter({ has: page.locator('svg') }).first()
);
```

This selector was matching multiple buttons on the page:
1. `button "Show visual canvas"`
2. `button "Switch to dark mode"`

This caused Playwright's strict mode to throw an error because it expects unique selectors.

### Fix Applied
The test file has already been updated to use the specific `data-testid` attribute that exists on the ThemeToggle component:

```typescript
// NEW (fixed)
const themeToggle = page.getByTestId('theme-toggle');
```

This selector uniquely identifies the theme toggle button and resolves the strict mode violation.
