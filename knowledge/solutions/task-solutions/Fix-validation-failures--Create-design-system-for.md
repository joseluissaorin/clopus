### Root Cause
The App component has multiple buttons with SVG icons:
1. **Canvas toggle button** - `aria-label="Show visual canvas"` or `"Hide visual canvas"`
2. **Theme toggle button** - `aria-label="Switch to dark mode"` or `"Switch to light mode"`

The regex pattern `/theme|dark|light|mode/i` in the test could potentially match multiple elements, causing Playwright's strict mode to fail.
