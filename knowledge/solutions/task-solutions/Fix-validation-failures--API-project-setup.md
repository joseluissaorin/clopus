## Problem

Fix validation failures: API project setup

## Solution

## Summary

**Problem:** The validation pipeline was failing at the `build` stage with an `externally-managed-environment` error. This is a PEP 668 protection that prevents pip from installing packages system-wide on modern Linux distributions (like Debian/Ubuntu with Python 3.12+).

**Root Cause:** The project had a `pip.conf` in the project directory (`/workspace/nexus-api/pip.conf`), but pip doesn't automatically read configuration from the current working directory. The validation pipeline was running pip commands that attempted to install packages globally.

**Solution:** Created a user-level pip configuration at `~/.pip/pip.conf` with:
```ini
[global]
break-system-packages = true
```

This tells pip to allow installations that might affect system packages, resolving the PEP 668 restriction.

**Result:** The build stage now passes validation (completed in ~5 seconds).
