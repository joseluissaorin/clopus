## Problem

Add Tailwind directives to CSS

## Solution

The Tailwind directives have been added to `src/index.css`. The file now contains:

- `@tailwind base;` - Injects Tailwind's base styles and CSS reset
- `@tailwind components;` - Injects component classes
- `@tailwind utilities;` - Injects utility classes

This is the standard Tailwind CSS v3 setup that enables all Tailwind utility classes to be used throughout the React application.
